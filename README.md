# Prnumbral Studios Archive

This archive of Penumbral Studios was made with Discord History Tracker.

## Files

- `Penumbral.dht` — message archive
- `Penumbral.dht_downloads` — downloaded attachments/media, not included because it is 33.7 GB

## How to open

1. Download Discord History Tracker.
2. Open `Penumbral.dht`.
3. Browse/search the archived messages.

Media attachments may be missing unless you also have the matching `dht_downloads` folder.
